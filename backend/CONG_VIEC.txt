3. CHI TIẾT CÔNG VIỆC TỪNG THÀNH VIÊN
================================================================================

--------------------------------------------------------------------------------
1. NHẬT (LEADER) - NHÁNH: nhat
--------------------------------------------------------------------------------
A. Phân hệ AUTH (src/features/auth/):
   - Đăng ký tài khoản mới: Mã hóa mật khẩu (bcryptjs), sinh mã OTP 6 số ngẫu nhiên.
   - Tích hợp gửi mail OTP qua Gmail SMTP (đã có sẵn tại 'src/shared/services/email.service.js').
   - Xác thực OTP và kích hoạt tài khoản (is_email_verified = true).
   - Đăng nhập: Kiểm tra mật khẩu, sinh JWT Token (dùng 'src/shared/utils/token.util.js').
   - Quên mật khẩu / Đặt lại mật khẩu bằng mã OTP.
   - Bảng DB liên quan: 'users'.
   - File hướng dẫn: src/features/auth/explain.txt.

B. Phân hệ EXPENSES (src/features/expenses/):
   - Thiết lập & theo dõi ngân sách chuyến đi, tổng chi, số tiền còn lại.
   - Ghi nhận khoản chi tiêu nhóm, phân loại danh mục (ăn uống, di chuyển, khách sạn...).
   - Chia tiền (Split Bill): Chia đều, chia theo %, chia theo số tiền cụ thể.
   - Thuật toán Dòng tiền cực tiểu (Min Cash Flow) tối ưu nợ chéo (dùng 'src/shared/utils/minCashFlow.util.js').
   - Sinh mã VietQR chuyển khoản nhanh theo chuẩn NAPAS (dùng 'src/shared/services/vietqr.service.js').
   - Bảng DB liên quan: 'expenses', 'expense_splits', 'settlements'.
   - File hướng dẫn: src/features/expenses/explain.txt.

C. Phân hệ AI-PLANNER (src/features/ai-planner/):
   - Tích hợp Google Gemini AI sinh lịch trình tự động theo yêu cầu (ngân sách, ngày đi, sở thích).
   - Chuẩn hóa đầu ra JSON để người dùng có thể import trực tiếp vào chuyến đi thật.
   - Bảng DB liên quan: 'trips', 'itineraries', 'itinerary_items'.
   - File hướng dẫn: src/features/ai-planner/explain.txt.

--------------------------------------------------------------------------------
2. PHÚ - NHÁNH: phu
--------------------------------------------------------------------------------
A. Phân hệ TRIPS (src/features/trips/):
   - CRUD chuyến đi: Tạo, cập nhật, xóa chuyến đi (điểm đến, ngày bắt đầu, ngày kết thúc).
   - Tạo mã Invite Code (6 ký tự) để các thành viên khác nhập mã tham gia nhóm.
   - Quản lý danh sách thành viên nhóm, phân quyền Trưởng nhóm (HOST) và Thành viên (MEMBER).
   - Tính năng Fork / Clone Plan từ lịch trình mẫu hoặc lịch trình cộng đồng.
   - Bảng DB liên quan: 'trips', 'trip_members'.
   - File hướng dẫn: src/features/trips/explain.txt.

B. Phân hệ ITINERARIES (src/features/itineraries/):
   - Lập và quản lý lịch trình chi tiết theo từng ngày (Day 1, Day 2...).
   - Thêm, sửa, xóa hoạt động trong ngày, thay đổi thứ tự, đánh dấu hoàn thành.
   - Thuật toán SMART SWAP (B -> B+): Gợi ý địa điểm thay thế tương đương cùng danh mục
     trong bán kính gần mà không làm lệch cung đường di chuyển.
   - Bảng DB liên quan: 'itineraries', 'itinerary_items', 'places'.
   - File hướng dẫn: src/features/itineraries/explain.txt.

--------------------------------------------------------------------------------
3. THÀNH - NHÁNH: thanh
--------------------------------------------------------------------------------
A. Phân hệ USERS (src/features/users/):
   - Lấy thông tin hồ sơ cá nhân (Profile) của người dùng đang đăng nhập (/me).
   - Cập nhật thông tin cá nhân: Họ tên, số điện thoại, ngày sinh, giới tính, bio.
   - Upload ảnh đại diện (Avatar) lên Cloudinary (dùng 'src/shared/middlewares/upload.middleware.js').
   - Cập nhật thông tin ngân hàng thụ hưởng (Tên ngân hàng, STK, Tên chủ TK) để nhận tiền chia bill.
   - Nộp ảnh/dữ liệu CCCD để gửi yêu cầu xác minh tích xanh eKYC.
   - Bảng DB liên quan: 'users'.
   - File hướng dẫn: src/features/users/explain.txt.

B. Phân hệ PLACES (src/features/places/):
   - Quản lý kho dữ liệu địa điểm du lịch, quán ăn, quán cà phê, điểm check-in ('places').
   - API tìm kiếm và lọc địa điểm theo từ khóa, thành phố, danh mục.
   - Tính khoảng cách địa lý giữa 2 tọa độ (công thức Haversine).
   - Thuật toán sắp xếp lộ trình tối ưu (Greedy / Nearest Neighbor) để các điểm trong ngày
     không bị đi vòng vèo, tiết kiệm thời gian di chuyển.
   - Bảng DB liên quan: 'places'.
   - File hướng dẫn: src/features/places/explain.txt.

4. HƯỚNG DẪN DÀNH CHO CÁC THÀNH VIÊN BẮT ĐẦU CODE
================================================================================
Bước 1: Chuyển sang nhánh của mình:
   git checkout <nhánh_của_bạn>
   (Ví dụ: git checkout phu)

Bước 2: Cập nhật code khung sườn mới nhất từ nhánh main:
   git pull origin main

Bước 3: Mở thư mục tính năng của mình trong 'src/features/<tên_tính_năng>/':
   - Đọc kỹ file 'explain.txt' trong thư mục để nắm rõ các API cần viết.
   - Viết code theo đúng 4 tầng:
     1. repository: Viết các câu lệnh SQL truy vấn Database.
     2. service: Xử lý logic nghiệp vụ và tính toán.
     3. controller: Nhận request và trả về response qua sendSuccess / sendError.
     4. routes: Định nghĩa endpoint API (router.get, router.post...).

Bước 4: Push code lên GitHub:
   git add src/features/<tên_tính_năng>/
   git commit -m "feat(<tên_tính_năng>): hoàn thành các api cơ bản"
   git push origin <nhánh_của_bạn>

Bước 5: Chờ GitHub Actions CI/CD tự động kiểm tra lỗi cú pháp và tự động merge vào main!
